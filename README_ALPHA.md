# JalmarQuest Alpha Release v0.1.0

## 🎮 Available Features

### Core Gameplay
- **Character Creation**: Name your tiny quail hero
- **Save/Load System**: 3 save slots with autosave every 5 minutes
- **Movement & Exploration**: Grid-based movement with stamina cost
- **World Map**: 7x7 viewport centered on player
- **Location Discovery**: Fog of war system reveals new areas

### World Systems
- **7 Biomes**: Grassland, Forest, Mountain, Swamp, Desert, Tundra, Cave
- **Dynamic Time**: Day/night cycle (20 ticks/second)
- **Seasons**: Spring, Summer, Autumn, Winter (30-day cycles)
- **Weather Effects**: Rain, snow, storms based on season/biome

### Movement & Navigation
- **Click-to-Move**: Click adjacent tiles to move
- **Pathfinding**: A* algorithm finds optimal paths
- **Stamina System**: Movement costs stamina (1-5 based on terrain)
- **Terrain Effects**:
  - Grassland: 1 stamina
  - Forest: 2 stamina
  - Desert: 3 stamina
  - Mountain: 4 stamina
  - Swamp: 5 stamina

### Player Stats
- **Level System**: Levels 1-50
- **Health Points**: 100 HP max
- **Stamina**: 100 stamina, regenerates over time
- **Magic Points**: 50 MP (future spells)
- **Experience**: Gain XP from exploration (future quests)

### UI Features
- **Interactive World Map**: Visual grid with biome colors
- **Player Info Panel**: Stats, location, coordinates
- **Hover Info**: See tile details on hover (desktop)
- **Touch Support**: Tap to move (mobile/tablet)
- **Save Notifications**: Confirmation when saving

### Technical Features
- **Cross-Platform**: Windows, Linux, Mac, Android, iOS
- **Performance**: 20 TPS game loop, optimized rendering
- **Thread-Safe**: All state mutations protected
- **Offline Play**: No internet required
- **Small Size**: ~15MB install

## 🎯 How to Play

### Controls
- **Desktop**: 
  - Click tiles to move
  - Hover for information
  - ESC for menu
- **Mobile**:
  - Tap tiles to move
  - Tap and hold for info
  - Back button for menu

### Getting Started
1. Create new game with your quail's name
2. Explore the world starting from Starting Village
3. Manage stamina while moving
4. Discover new locations
5. Save your progress regularly

### Tips
- Different terrains cost different stamina
- Rest to restore stamina
- Explore to find new areas
- Check coordinates to navigate
- Save before risky exploration
