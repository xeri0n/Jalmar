# Resources Directory

## Adding the Main Menu Background Image

To use the beautiful JalmarQuest artwork as the main menu background:

1. Save the image file as `main_menu_background.png` in this directory
2. The image should be the one showing Jalmar (the button quail) with the blue butterfly in the forest

The code is already configured to use this image with:
- Full-screen crop scaling
- A subtle dark overlay (30% opacity) for better text readability
- White text with drop shadows for contrast

## File Location
```
composeApp/src/commonMain/resources/main_menu_background.png
```

## Supported Formats
- PNG (recommended for best quality)
- JPG/JPEG
- WebP

The image will be automatically loaded by Compose Multiplatform's resource system.
