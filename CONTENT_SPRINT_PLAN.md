## Phase 1: Item Catalog Expansion (24 → 200+)

### Categories & Target Distribution

**Materials (70 items)**
- Common Materials (30): Seeds, twigs, leaves, grass, bark, stones, etc.
- Uncommon Materials (25): Spider silk, rare feathers, crystals, metals
- Rare Materials (15): Gems, magical components, ancient artifacts

**Equipment (60 items)**
- Weapons (20): Spears, daggers, bows, staves (twig-scale)
- Armor (20): Helmets, chest pieces, leg guards (acorn-scale)
- Accessories (20): Charms, rings, amulets (feather-scale)

**Consumables (40 items)**
- Food (15): Seeds, berries, grains, water
- Potions (15): Health, stamina, buffs (dewdrop-based)
- Utility (10): Bombs, traps, tools

**Quest Items (30 items)**
- Lore Fragments (15): Historical documents
- Keys & Maps (10): Unlock areas, reveal secrets
- Special Items (5): Unique quest objectives

### Design Principles

1. **Authentic Re-contextualization**: All items transform mundane → epic
   - Twig → Twig Spear ✅ (already done)
   - Acorn Cap → Acorn Helmet ✅ (already done)
   - Safety Pin → Ancient Gate Key (new)
   - Bottle Cap → Shield of the Ancients (new)
   - Paper Clip → Grappling Hook (new)

2. **Quail-Scale Realism**: All weights in milligrams
   - Small twig: 500mg (0.5g)
   - Acorn cap: 300mg (0.3g)
   - Pebble: 2000mg (2g - heavy for quail!)
   - Feather: 50mg (0.05g - ultra-light)

3. **Rarity Distribution**:
   - Common: 60% (120 items)
   - Uncommon: 25% (50 items)
   - Rare: 12% (24 items)
   - Epic: 3% (6 items)

**Material Processing (10)**

### Design Principles

1. **Progression Tiers**: Early/Mid/Late game balance
2. **Material Loops**: Recipes create demand for gathering
3. **Grumble Forgepaw Integration**: All recipes craftable at The Quailsmith
4. **Complexity Scaling**: Simple (2 inputs) → Complex (5+ inputs)

## Content Quality Checklist

Every item must have:
- ✅ Unique ID (snake_case)
- ✅ Descriptive name (Title Case)
- ✅ Authentic description (mundane → epic transformation)
- ✅ Realistic weight (milligrams, quail-scale)
- ✅ Appropriate rarity (distribution curve)
- ✅ Proper type (material/equipment/consumable/quest)

Every enemy must have:
- ✅ Unique ID and name
- ✅ Lore-friendly description
- ✅ Level-appropriate stats (HP, strength, agility, etc.)
- ✅ Behavior type (aggressive/defensive/fleeing/strategic)
- ✅ Biome-appropriate loot table
- ✅ XP reward (balanced for level)

Every recipe must have:
- ✅ Unique ID matching output item
- ✅ Clear inputs (items that exist in ItemCatalog)
- ✅ Single output (item that exists in ItemCatalog)
- ✅ Required level (progression gating)
- ✅ Category (equipment/consumable/material/upgrade)

Every quest must have:
- ✅ Unique ID and name
- ✅ Engaging narrative description
- ✅ Clear objectives (trackable)
- ✅ NPC integration (questgiver, rewards)
- ✅ Butterfly Effect tracking (choices logged)
- ✅ Rewards (XP, items, abilities, relationships)

Every NPC must have:
- ✅ Unique ID and name
- ✅ Personality description
- ✅ Location (where player finds them)
- ✅ Dialogue tree outline
- ✅ Quest relationships (if applicable)
- ✅ Relationship tracking integration
